Current Affairs 2026 — Labour Laws & Social Security

UPSC EPFO (APFC / EO-AO) · for the December 2026 exam

 

MOST IMPORTANT DEVELOPMENT: The four Labour Codes came into force on 21 November 2025. This is the single biggest current-affairs point for these subjects — expect direct questions. The old Acts are now being replaced by the Codes; study the Codes as current law.

1 · Labour Codes now in force (21 Nov 2025)

●        Commencement: All four Codes — Code on Wages 2019, Industrial Relations Code 2020, Code on Social Security 2020, OSH Code 2020 — came into force on 21 November 2025, consolidating 29 central labour laws into 4 Codes.

●        Central rules: Draft central rules notified end-Dec 2025; final central rules published 8–9 May 2026. State rules are still being aligned (labour is a Concurrent-List subject).

●        Recommended by: The Second National Commission on Labour (2002) had recommended this consolidation.

●        Structure recap: Wages Code = 4 laws; IR Code = 3; Social Security Code = 9; OSH Code = 13.

Key operative changes now in effect

●        50% wage rule (Sec 2(y), Code on Wages): 'wages' = basic + DA must be at least 50% of total remuneration — raises the PF/gratuity base.

●        Fixed-term employees: pro-rata gratuity after just 1 year of service (Sec 53, Social Security Code) — the 5-year rule no longer applies to them.

●        Gig & platform workers: given statutory social security for the first time (Chapter IX, Secs 109–114); aggregators to contribute 1–2% of annual turnover to a welfare fund.

●        ESI: extended nationwide (no longer limited to notified areas); may cover hazardous units with fewer employees, and contract/casual/fixed-term/certain gig workers.

●        Standing Orders now mandatory at 300+ workers; single-window registration/licence/return across all four Codes.

2 · Social Security Code — operationalisation

●        In force: Code on Social Security, 2020 operational since 21 November 2025; final rules notified 8 May 2026.

●        EPF Scheme, 2026: Notified; came into effect 29 June 2026 — replaces the EPF Scheme, 1952. Modernises digital compliance, portability and partial-withdrawal rules.

●        EPF contribution unchanged: 12% + 12% retained; 10% rate continues for notified establishments; wage ceiling retained at ₹15,000/month.

●        EPF officers redesignated: EPF officers designated as 'Inspectors-cum-Facilitators' and Recovery Officers under the Code.

●        ESI figures (as of mid-2026): Wage ceiling ₹21,000/month (₹25,000 for persons with disability); contribution employer 3.25% + employee 0.75%. A hike to ₹25,000–30,000 has been proposed but NOT yet notified.

Watch item: The new 'wages' definition (basic + DA, 50% rule) can pull previously-excluded employees inside the EPF/ESI ceilings even without a ceiling change — a likely conceptual question.

5 · How this is likely to be tested

●        Direct: the commencement date (21 November 2025) and 'which Code merges which laws'.

●        Provisions: the 50% wage rule, fixed-term pro-rata gratuity (1 year), aggregator 1–2% contribution, gig/platform coverage chapter.

●        Figures: EPF rate 8.25% (FY26), EPF/ESI wage ceilings (₹15,000 / ₹21,000), EPF Scheme 2026 replacing the 1952 Scheme.

●        Bodies/people: CBT chaired by the Union Labour Minister; EPFO 3.0; Inspectors-cum-Facilitators.

●        Static-vs-current trap: where an old Act figure differs from the Code, the Code is now the current law — but the wage ceilings (₹15,000 / ₹21,000) were retained, so those numbers are unchanged.
