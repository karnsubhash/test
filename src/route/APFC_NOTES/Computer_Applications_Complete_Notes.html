1 · Number Systems (guaranteed marks)

Conversion

Method / worked example

Hex → decimal

multiply each digit by 16^n (right→left). 5A6D = 5·4096 + 10·256 + 6·16 + 13 = 23149

Octal → binary

each octal digit → 3 bits. 473 = 100 111 011

Binary → decimal

multiply each bit by 2^n

Decimal → binary

repeated division by 2, read remainders bottom-up

Bases

Binary (2, 0-1), Octal (8, 0-7), Decimal (10), Hexadecimal (16, 0-9 A-F)

●        Units: bit → nibble (4 bits) → byte (8 bits) → KB → MB → GB → TB (×1024)

2 · Hardware & Memory

Item

Key point

Permanent (non-volatile) memory

Hard Disk, SSD, ROM — retain data without power. RAM is volatile (temporary)

Primary vs Secondary memory

primary = RAM & ROM (directly accessed by CPU); secondary = HDD/SSD/optical/USB

Cache & registers

fastest memory; registers are inside the CPU

SSD

no spinning parts; consumes LESS energy than an HDD; can serve as virtual memory; CANNOT replace the processor

CPU parts

ALU (arithmetic/logic), Control Unit, registers; GPU preferred for training complex AI models (parallel processing)

Software types

system software (OS, utilities) vs application software; firmware

Important CPU registers

Register

Function

MAR (Memory Address Register)

holds the ADDRESS of the memory location to be accessed

MBR / MDR (Memory Buffer/Data Register)

holds the DATA read from / written to memory

PC (Program Counter)

holds the address of the NEXT instruction

IR (Instruction Register)

holds the current instruction being executed

Accumulator

holds intermediate arithmetic/logic results

3 · Operating Systems

●        Function: manages hardware/software resources — process, memory, file and device management

OS type

Key point

Real-time OS

responds to an event within a fixed/predetermined time (e.g. control systems)

Batch OS

jobs processed in batches, no user interaction

Time-sharing / Multitasking

CPU time shared among many users/tasks

Multiuser vs Multiprogramming

multiple users / multiple programs in memory

Embedded OS

runs on a dedicated device (appliance, IoT)

Distributed OS

manages a group of networked computers as one

●        Key OS commands: CHKDSK checks the error status of a hard disk; other DOS/CLI utilities

4 · Networking & Internet

Item

Key point

Network types

LAN (local), MAN (metro), WAN (wide, e.g. the Internet), PAN

Topologies

Bus, Star, Ring, Mesh, Tree. Full mesh links = n(n−1)/2 → 6 computers = 15 links

IP address (IPv4)

four octets, each 0–255 (so '710' is INVALID); IPv6 uses 128 bits

SSL

Secure Socket Layer — encrypts data on banking/secure websites (HTTPS)

Protocols

TCP/IP, HTTP/HTTPS, FTP, SMTP (email), DNS (name→IP)

Devices

router, switch, hub, modem, gateway

5 · Programming & Web Basics

Item

Key point

Top-down (procedural) languages

C, FORTRAN, Pascal, COBOL. JAVA is object-oriented (bottom-up)

Language levels

machine (binary) → assembly → high-level; compiler vs interpreter

Dot operator

connects a structure variable and its member/element (e.g. student.name)

HTML internal linking

uses the name / id attribute (a named anchor) to link within a page

Data structures

array, stack (LIFO), queue (FIFO), linked list, tree

Number of key generations

1st vacuum tubes, 2nd transistors, 3rd ICs, 4th microprocessors, 5th AI

7 · Emerging Tech & Digital Policy (Current Affairs)

The small current-affairs slice of this subject. Biggest development: the DPDP Rules, 2025 were notified on 13 November 2025, operationalising India's data-protection law — a likely factual question.

Item

Detail

DPDP Act, 2023 + DPDP Rules, 2025

Digital Personal Data Protection framework; Rules notified 13 Nov 2025 by MeitY; phased rollout; sets up the Data Protection Board of India (DPBI); 'data fiduciary' & 'data principal'

IndiaAI Mission

₹10,000+ crore national AI mission — compute (GPUs), datasets, safety; IndiaAI Safety Institute

AI Governance Guidelines (Nov 2025)

MeitY 'light-touch' principles for responsible AI (non-binding)

Artificial Intelligence

ChatGPT is based on a Large Language Model (LLM); ML, deep learning, neural networks, generative AI; BharatGen (indigenous LLM)

Cybersecurity

CERT-In (national nodal agency for cyber incidents); malware, phishing, ransomware; firewall, encryption; SEBI/RBI cyber frameworks

Digital Public Infrastructure (DPI)

Aadhaar, UPI (record transaction volumes), ONDC, DigiLocker, Account Aggregator

Other terms

cloud computing (IaaS/PaaS/SaaS), blockchain, IoT, quantum computing, semiconductors (India Semiconductor Mission)
